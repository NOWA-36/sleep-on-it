# sleep-on-it

衝動買いを防ぐための、欲しい物を「寝かせて考える」ためのミニアプリ。

## Concept
- 欲しい気持ちは否定しない
- ただし、即決はしない
- 7日間「時間に預ける」

## MVP Scope
- 欲しい物の登録（タイトル必須、メモ任意）
- 登録日から7日間は判断不可
- 7日後に「いらない / まだ欲しい」を判断
- 「いらない」は即削除
- 「まだ欲しい」は理由を記録

## Tech Stack
- Next.js (App Router)
- TypeScript
- Prisma
- SQLite
